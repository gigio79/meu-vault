# 🎨 Prompt para gerar a Logo — O Código Oculto

Envie este prompt para um agente/ferramenta de geração de imagem (ex: Midjourney, DALL-E, Leonardo, Ideogram) para criar versões mais elaboradas da logo.

---

## **Prompt PRINCIPAL (logo do canal):**

> Create a powerful, mysterious logo for a YouTube channel called "O Código Oculto" (Portuguese for "The Hidden Code"). Style: esoteric, mysterious, premium, occult knowledge. 
>
> Main symbol: a glowing golden **All-Seeing Eye** inside a triangle, surrounded by subtle binary code (0101) and geometric lines suggesting a hidden code or encryption. 
>
> Color palette: deep dark purple/violet background, golden yellow accents, subtle white glow. Mystical, intelligent, secretive atmosphere — evokes hidden knowledge, the power of the mind, and transformation.
>
> Typography: elegant serif text below reading "O CÓDIGO OCULTO" in gold. Clean, scalable, vector-style logo suitable for avatar, banner, and thumbnail. No text other than the channel name. Premium, cinematic, mysterious energy.

---

## **Variações (escolha uma que preferir):**

### Variação A — Olho + Triângulo (recomendada)
> Logo with a golden all-seeing eye inside a pyramid/triangle, dark purple background, thin golden geometric lines and faint binary code around it, elegant gold serif text "O CÓDIGO OCULTO" below. Mysterious, premium, esoteric.

### Variação B — Código/Encryption
> Logo featuring abstract encrypted symbols, ancient-looking geometric patterns and a subtle glowing keyhole, dark background with gold and teal accents, text "O CÓDIGO OCULTO" in elegant gold serif. Represents a hidden code to be deciphered.

### Variação C — Livro/Brain + Mistério
> Open mystical book with a glowing mind/brain emerging, surrounded by floating esoteric symbols and faint gold binary code, dark violet background, "O CÓDIGO OCULTO" in gold serif below. Knowledge + mind + mystery combined.

### Variação D — Minimal (avatar clean)
> Ultra-minimal circular avatar: just a gold all-seeing eye in a thin gold triangle on plain dark purple, no text (works as small YouTube avatar). Clean, bold, recognizable at small sizes.

---

## **DICAS pra melhor CGAR:**
- **Tamanhos usados:** Avatar YouTube = 800x800px (quadrado). Banner = 2560x1440px. Thumbnail = 1280x720px.
- A logo deve ficar **bem pequena** (avatar de 40px) e **bem grande** (vídeo). Evite detalhes que se perdem.
- Mantenha **CINZA/DIVROXO/DOURADO** consistentes pra criar identidade reconhecível.
- Peça sempre **vetor/vector style** pra não ficar com bordas ruins.
