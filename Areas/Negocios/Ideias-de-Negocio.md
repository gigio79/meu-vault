# 💡 Ideias de Negócio

## Canal de Validação
1. Ideia entra aqui (Inbox ou direto)
2. Classificar: 💎 Ouro / 🥈 Prata / 🥉 Bronze
3. Se 💎 ou 🥈 → mover pra `Projects/Ativos/` com template Projeto
4. Testar com MVP mínimo
5. Se funcionar → escalar. Se não → lixeira.
